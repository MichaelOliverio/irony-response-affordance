## Experiment 2: perspective conditioning

Run `python 3_experiments/experiment2/eval_perspectives.py` from the repository
root to compare Neutral and Conditioned predictions against the same perspective
proxy labels. Results are written to `experiment2/output/perspectives/`.
See [the analysis protocol and results](experiment2/perspectives_analysis.md)
for paired cluster resampling, coverage, reproducibility commands, and inference
provenance limits. The historical Global–Perspective analysis remains in
`experiment2/eval.py` with separate outputs.
